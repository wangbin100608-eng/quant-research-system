## 2. 关键行为变更

### 可信验收（修复 v03 漏洞）
- 每项检查输出 `{id, description, input, execution, result, failure_reason, executed_at}`；`result ∈ PASS/FAIL`。
- **真实执行 pytest** 并解析 passed 数；报告中数量 > 实际数量 → FAIL（测试丢失）；允许新增测试使实际数增加。
- 篡改测试报告（临时副本 summary 改 0 passed）→ 检查 04 FAIL。
- 核心模块缺失 → 检查 02 FAIL；模块路径校验 → 检查 03。
- 六库检查改为实际 SQL 分组（库名 + 行数 + min/max available_time）。
- 时间隔离负向测试：注入 2099 年数据必须被剔除/拒绝。
- 任一 P0 失败 → `overall=FAIL`。输出新文件 `final_acceptance_v04.json`，不改 v03 报告。

### 统一时间内核
- 统一字段 `event_time / published_at / available_at / ingested_at / revision_time`；旧字段保留兼容（`migrate_record` 不删旧列）。
- cutoff(Y) = `Y-1-12-31T23:59:59Z`；所有时间 UTC aware；市场时区（CN_A/US）按 IANA 转换。
- `TimeGuardReader.read_parquet()` 强制列投影 + available_at 过滤，future/unknown 在 strict 模式拒绝/剔除，返回 ReadAudit。
- Rust `parse_utc_epoch` 与 Python `cutoff_for_year` 一致；selftest 向量 `2001-12-31T23:59:59Z=1009843199`，非 UTC 尾缀拒绝。
- `migrate_v04.py` 前向加列并回填、回滚删列；**仅在临时副本验证**，真实 data/meta.db 未改。

### 宏观字段
- ALFRED vintage 记录 `vintage_version`（来自 header 后缀）、`first_release_date`（估计，按季度近似）、`first_release_basis=estimated_quarterly`；准入仍用真实 `vintage_date`（`real_published`），估计字段不作为严格验证依据。

### A股真实日线
- 适配器已实现分批（20/批）、指数退避（2^n）、原始响应 SHA-256、异常价格/成交量剔除。
- 东财 kline 当前仍限流（返回空），**未抓到真实日线**；如实记录 BLOCKED，不用合成数据补齐；v0.2 的 fixture A股日线未混入真实数据集。
