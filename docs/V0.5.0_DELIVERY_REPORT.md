## 二、关键能力变更

1. **可信验收 v05**：模块删除→FAIL→恢复→PASS 闭环；报告四类篡改（passed/total/timestamp/commit）全部检测；Parquet/DuckDB/KB 三接口未来数据注入均不可见；每项记录 started_at/finished_at/duration、环境、commit；任一 P0 FAIL → exit code 1。
2. **预测冻结 v05**：记录 prediction_id/年份/数据快照/模型版本/特征版本/code commit/训练数据最大 available_at/预测 cutoff/frozen_at/SHA-256/HMAC 链；append-only 触发器禁止修改删除；修正必须生成新版本并记录原因。
3. **溯源审计 v05**：Embedding 记录 doc_id/模型版本/生成时间/源文档 max available_at/snapshot_id/向量库版本；模型记录训练快照/时间/归一化/填充/特征选择/超参范围/验证范围/种子/环境/权重哈希；Agent 访问日志持久化（工具/文档/快照/cutoff/允许与否）。
4. **流式数据引擎**：`ParquetFile.iter_batches` 分批读 + 分批过滤，不构建全量 Python 列表；100 万行内存峰值 84.6MB→10.46MB，结果行数一致。
5. **历史股票池与质量**：按年构建快照，退市股按真实上市/退市日期保留（防幸存者偏差）；指数成分/行业为当前版本参考不冒充历史；数据质量评分 66.7（含缺失/重复/异常价格/成交量/时间顺序/来源）。
