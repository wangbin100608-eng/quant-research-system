## 二、关键变更

- **股票池 PIT**（`data_quality_v05.py`）：每年 cutoff=`Y-1-12-31T23:59:59Z`；退市记录双时间校验（信息发布时间+真实退市日期）；2099 才发布的退市信息不进入 2002 池；指数成分/行业当前名单标 BLOCKED；输出 source_stats/time_audit 与可复现 SHA-256。
- **列投影门禁**（`timeguard_reader.py`）：无论用户传何列，内部自动读 available_at/available_time 过滤，再投影回用户列；支持空列/单列/多列/旧字段/缺失字段；全量与流式一致。
- **流式审计**：每批独立统计 rows_in/out/dropped_future/unknown + 累计、batch_index/batch_size、文件大小、流式 SHA-256、耗时、中断状态。
- **验收器**（`final_acceptance_v05.py`）：历史报告缺失→FAIL；DuckDB 注入走真实 query_sql；Parquet 异常区分拒绝/意外；版本化 manifest；非零退出码。
- **强制门禁**（`enforcement_v060.py`）：Agent 调用必须带 snapshot_id/cutoff、文档 available_at 校验、越权持久化；Embedding 全溯源（doc_sha256/model_file_hash/config/cutoff/快照哈希）与跨快照隔离；模型选择不得引用最终测试集。
- **预测冻结**：必需字段校验、输入/输出双 SHA-256、密钥版本、不含密钥本体。
- **数据质量**：Arrow RecordBatch 分批、NaN/Infinity/OHLC 一致性、9 项逐项检查 + 三维评分；数据现状报告区分真实/估算/合成。
- **统计可信度**（`stats_v060.py`）：Bootstrap CI、Bonferroni 校正、证据等级、Mann-Whitney。
- **性能**：100 万行 RSS 208MB（增量 58.68MB，13.5s）；500 万行 RSS 208MB（增量 0，53.8s），内存稳定。
